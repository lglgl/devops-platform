## 自动更新结果（未完全成功，已回滚保全）
- 6 组件中：**ingress-nginx✅**(4.15.1)、**loki✅**(3.7.8)、**tempo✅** 成功。
- **kube-prometheus-stack**：升到 chart 92.3.0 后 Grafana 新 pod 崩溃，根因 `datasource.yaml: Only one datasource per organization can be marked as default`（新版 chart 与现有 Grafana 配置冲突）→ `helm rollback` 到 rev3(91.8.2) 恢复。
- **alloy**：升到 v1.20.1 时镜像 `grafana/alloy:v1.20.1` 被 Docker Hub EOF 拉不下来 → rollback 到 rev2(v1.20.0) 恢复。
- **cicd**：Argo CD chart(10.10.2) 从 GitHub 下载 EOF，在 `helm template` 校验阶段失败、未执行任何 helm upgrade（Jenkins/ArgoCD 保持旧版健康）。
- 根因：① 网络拉取 chart/镜像不稳定（gitlab/harbor/grafana/jenkins/argo/prometheus-community 等仓库间歇性 EOF/超时）；② 最新 kube-prometheus-stack 92.3.0 与本项目 Grafana 配置冲突。
- 建议：为可重复更新，应在 values 中 pin chart 版本（如 kube-prometheus-stack 91.8.2、alloy 1.13.0）避免 surprise 升级；Grafana 92.3.0 需先在 values 解决 default datasource 冲突再升。
- 已知无关项：`kube-prometheus-stack-prometheus-node-exporter` 在 mac docker-desktop 长期 CrashLoopBackOff(1177)，属 mac 兼容性（项目另有 macos-node-exporter），与本次更新无关。
